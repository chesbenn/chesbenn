# 04. Мгновенный расчёт стоимости подключения

**Коротко:** человек или компания вводит адрес — и сразу получает цену и срок подключения: «Ваш дом уже подключён — 0 ₽, завтра», «Нужно протянуть 180 м от опоры — 7 400 ₽, 5 дней», «Для офиса: 1 Гбит/с с SLA — 15 000 ₽ подключение и 9 000 ₽/мес». Расчёт идёт по реальной карте сети, а не «оставьте заявку, мы перезвоним».

---

## Проблема
- Частные дома, коттеджные посёлки, офисы и склады ждут ответа «можно ли подключиться и за сколько» днями. Многие уходят к тому, кто ответил первым.
- Инженер вручную смотрит карту, считает метры кабеля и материалы — это часы работы на каждую заявку, большинство из которых не превращаются в подключения.
- Цены считаются «на глаз» и часто не окупают стройку.

## Что делает
1. **Проверяет адрес:** уже подключён / рядом есть сеть / сети нет.
2. **Находит ближайшую точку подключения:** свободный порт сплиттера, муфта, опора, узел с ёмкостью.
3. **Строит трассу:** по опорам, существующим трассам, дорогам — до дома (кратчайший допустимый путь).
4. **Считает смету:** кабель (м), крепёж, опоры (если нужны новые), ONU/роутер, работа, согласования.
5. **Учитывает ёмкость:** есть ли свободные порты; если нет — добавляет стоимость нового сплиттера.
6. **Показывает цену и срок** с вариантами: «подключение сразу 7 400 ₽» или «рассрочка 12 × 650 ₽» или «0 ₽ при договоре на 24 месяца».
7. **Для бизнеса** — коммерческое предложение (PDF) с тарифами, SLA, резервированием.
8. **Собирает спрос:** если подключение дорого, предлагает «объединиться с соседями» — цена падает, когда соберётся N заявок (связка со сбором спроса).
9. **Передаёт заявку** в онлайн-запись на монтаж (модуль 05) после согласия.

## Кто пользуется
| Роль | Что делает |
|---|---|
| Потенциальный клиент | Вводит адрес на сайте/в боте, получает цену |
| Менеджер продаж | Видит заявки с готовой сметой, правит, отправляет КП |
| Инженер | Проверяет сложные случаи (длинные трассы, переходы через дороги) |
| Руководитель | Настраивает цены материалов, наценки, правила окупаемости |

## Как работает
```
Адрес → geo: нормализация, координаты
  → graph: адрес уже подключён? (есть активная услуга / свободный порт в доме)
        да → "уже есть сеть": цена = стандартное подключение, срок = ближайший слот
  → поиск точек подключения в радиусе R (по умолчанию 1 км):
        объекты kind in (splitter, closure, pole, node_site) с свободной ёмкостью
  → для каждой из 3 ближайших точек: построение трассы
        граф путей = опоры + существующие трассы + дороги (OSM) с весами:
          по существующим опорам: 1.0, новая опора: +стоимость, переход дороги: +штраф,
          запрещённые зоны (ж/д, частная территория) — исключены
        алгоритм: Дейкстра / A* (pgRouting)
  → смета по каждому варианту (таблица цен) → выбрать лучший
  → проверка окупаемости: стоимость / (ARPU × месяцы) — если > порога, предложить
        условия (договор на N мес, частичная оплата, сбор соседей)
  → ответ клиенту: цена, срок, варианты оплаты, карта трассы (упрощённо)
  → при согласии → заявка + бронь слота (модуль 05)
```

## Данные
| Данные | Источник |
|---|---|
| Сеть: сплиттеры, муфты, опоры, узлы, ёмкость | Граф (Userside/ГИС/OLT) |
| Дороги, здания, запретные зоны | OpenStreetMap (импорт в PostGIS) |
| Цены материалов и работ | Справочник (ведёт руководитель), склад |
| Тарифы | Биллинг |
| Средний ARPU, отток по районам | Аналитика |


## Правила
- **Когда нужен инженер:** трасса > 500 м; переход через железную дорогу/водоём; нужна новая опора на чужой земле; бизнес с резервированием. Клиенту показывается «предварительная цена от … ₽, инженер подтвердит в течение 1 дня».
- **Окупаемость:** если `стоимость_для_провайдера / маржа_в_месяц > 24`, автоматически предлагается договор с минимальным сроком или доплата.
- **Ёмкость:** при < 2 свободных портов на сплиттере — стоимость нового сплиттера + отметка «требуется расширение».
- **Срок:** стандартное подключение = ближайший слот монтажа; стройка = длина × норматив + согласования.
- Цена фиксируется на 14 дней (`valid_until`).

## Интерфейсы
- **Виджет на сайт** (одна строка кода) и **бот:** поле адреса → цена за 5 секунд.
- **Mini App:** с картой и выбором варианта оплаты.
- **Панель продаж:** очередь заявок, правка сметы, генерация КП (PDF) для бизнеса.
- **API для партнёров** (застройщики, агентства недвижимости): `POST /quotes`.

## Интеграции
`geo` (PostGIS + pgRouting + OSM), `graph`, склад (цены), биллинг (тарифы), модуль 05 (запись), модуль 13 (застройщики), модуль сбора спроса.

## Метрики
- Доля заявок с ответом < 1 мин (цель > 80%).
- Конверсия «расчёт → подключение».
- Отклонение фактической стоимости стройки от расчётной (цель ±15%).
- Экономия часов инженеров.

## Риски
- Неточная карта опор и трасс — первые месяцы инженер подтверждает все расчёты > 200 м; расхождения улучшают данные.
- Клиент может воспринять предварительную цену как окончательную — явно указывать «предварительно» для сложных случаев.

## MVP (2–3 недели)
Проверка «дом подключён / рядом сеть / нет сети» + расстояние по прямой до ближайшей точки × коэффициент + таблица цен → цена «от». Трассировка по опорам и дорогам — вторым шагом.

## Как проверить
1. Адрес подключённого дома из демо → «0 ₽ / стандарт, срок — ближайший слот».
2. Частный дом в 180 м от опоры → трасса по опорам, смета, срок.
3. Дом в 2 км от сети → «нужен инженер», предложение собрать соседей.

## Зависимости
`geo` (PostGIS, pgRouting, OSM), `graph`, справочник цен, биллинг, модули 05 и 13.
